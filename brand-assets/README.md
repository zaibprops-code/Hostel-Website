# Riwaq Hostels — Brand assets

Ready-to-use logo exports and their source.

| File | Size | Use |
| --- | --- | --- |
| `riwaq-logo-named.png` | 2048×2048 | Full logo (arch mark + "Riwaq" wordmark + HOSTELS) on forest green. Social profile pictures, avatars, share images. |
| `riwaq-logo-mark.png` | 2048×2048 | Symbol only (the Riwaq arch). Cleanest at very small sizes / circular crops (favicons, app icons, small avatars). |
| `logo-named.html` / `logo-mark.html` | — | Vector source. Open in a browser and screenshot at any resolution to re-export. |

**Palette:** forest green `#123a30` (deep `#0b201b`), brass gold `#d7ba70`, ivory `#faf7f0`.
**Fonts:** Fraunces (display / wordmark), Inter (the HOSTELS label).

The same arch mark also lives in the app as `src/app/icon.svg` (favicon) and the
`ArchMark` component in `src/components/brand/Logo.tsx`.
